# Ejemplos con React y Tailwind CSS

Aplicación de ejemplo con tres vistas, accesibles desde los enlaces `#app`,
`#flex` y `#grid`.

## Iniciar en desarrollo

```sh
npm install
npm run dev
```

## Desplegar en GitHub Pages

En GitHub, configura **Settings → Pages → Build and deployment → Source** como
**GitHub Actions**. Después, cada push a `main` ejecutará lint, build y
despliegue. También puedes iniciar el workflow manualmente desde la pestaña
**Actions**.
